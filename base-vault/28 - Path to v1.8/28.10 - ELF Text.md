# ELF `.text` loader

## API

```text
load_elf_text(path) -> ElfText { bytes, vma, name, is_64 }
lift_x86_32(&bytes, name) -> Module
```

- Aceita **ELF32** e **ELF64** **x86 / x86_64** apenas (`Architecture::I386` \| `X86_64`).
- Secção preferida: `.text`; fallback: primeira secção `SHF_EXECINSTR`.
- **Não** resolve relocs/symbols para call targets (emit = `ud2` + comentário).
- Gaps → `gaps_markdown` no `RECOMP_REPORT.md`.

## Honesty

ELF freestanding ≠ PE · ≠ libc linking · `win32_abi_complete: false`.
