# Use Case: iMac G3 late 2001 → Haiku + ReactOS validation assist

## Sistema original

| Componente | Especificação |
|------------|--------------|
| CPU | PowerPC G3 (750) |
| Máquina | iMac G3 (Flat Panel / CRT late 2001) |
| Firmware | OpenFirmware |
| Chipset | MacIO / Uni-N (típico New World) |
| OS stock | Mac OS 9 / OS X early |
| Port alvo | ReactOS (PPC *retired* upstream) + Haiku (PPC experimental) — builds **externos** |

## Papel do B.A.S.E. (v1.4+)

| Fase | Entrega |
|------|---------|
| A | Contratos OF/MacIO + dual `port package` (`hal_reactos_ppc_assist` / `hal_haiku_ppc_assist`) |
| B | Smoke QEMU `mac99`/`g3beige` — referência LinuxPPC/OpenBSD primeiro; Haiku/ReactOS se imagem existir |
| C | Playbook boot em iMac Late 2001 físico (depois de B verde) |
