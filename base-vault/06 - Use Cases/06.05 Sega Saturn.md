# Use Case: Sega Saturn — HW discovery assist (port shortcut)

## Sistema

| Componente | Spec |
|------------|------|
| CPU | 2× Hitachi SH-2 |
| GPU | VDP1 (sprites) + VDP2 (backgrounds) |
| Áudio | SCSP |
| I/O | SMPC |
| Media | CD |

## Papel do B.A.S.E.

| Fase | Entrega |
|------|---------|
| A | Contratos MMIO VDP/SMPC + `hal_saturn_assist` atlas |
| B | Smoke `base recomp` SH-2 (`runs_on_saturn=false`) |
| C | Lab com traces reais (Mednafen / HW) |

**Atalho:** descobrir o que o hardware faz → acelerar ports **humanos** PS1 / x86 90s → Saturn.  
**Não** gera jogos a correr. **Não** é runtime VDP.

Pilot: `examples/pilot_saturn/`  
Plugin isolado PS1→SRL: `plugins/psx-saturn-bridge/` (psxrecomp ref + SaturnRingLib)  
Irmão futuro: Dreamcast (x86/PS2 → DC, SH-4/PowerVR).
