# Platform RE Manifesto — B.A.S.E. sem IA no núcleo

> **B.A.S.E. — reverse engineering de hardware e firmware evidence-driven: contratos, tensão Ψ e API própria. Sem IA no núcleo.**

## Tese

O mercado vende disassemblers + “AI summarize”. Nós vendemos **prova do comportamento**: evidência imutável → contratos → SMT/Ψ → atlas → receipt — consumível pela **API própria** (`base-api`).

## Pilares únicos (não-IA)

| Pilar | Tecnologia | Entrega |
|-------|------------|---------|
| Evidência | Evidence DB + MMIO/traces | Auditável |
| Comportamento | BIR + contratos temporais | Ordem + latência |
| Formal | SMT (`prove`) | SAT/proved por contrato |
| Tensão | Ψ(B,H) → confidence | Score hipótese vs observação |
| Raciocínio | QRM / belief / triad | Perguntas estruturadas |
| Atlas | `port package` | HAL assist para engenheiros |
| API | `/v1/identify` · `/v1/prove` · `/v1/usage` | Pay-as-you-go (lab → Stripe) |

## Núcleo vs margem

- **Núcleo (sagrado):** evidence, contracts, SMT, Ψ, honesty gates, API meter — **sem** Transformer/ONNX.
- **Margem (opcional futuro):** qualquer assist generativo **fora** do path de prova; nunca altera `proved` / receipts.

## API canónica v1

| Endpoint | Papel |
|----------|--------|
| `POST /v1/identify` | FW + MMIO → blocos + identificação **por contrato** |
| `POST /v1/prove` | YAML de contratos → proof report |
| `GET /v1/usage` | Créditos / units consumidos |

Spec: [`base-api/openapi.yaml`](../../base-api/openapi.yaml) · crate `base-api`.

## Claims

**Permitidos:** evidence-driven RE HW/FW · contratos · Ψ · API própria · consultoria SOW.  
**Proibidos:** RE mágica · auto-fix · gera OS · PCB fabricável · HIL production · “IA faz o port”.

## Norte de produto

1. Wedges REAL\* (RP / STM32 / …) + goldens  
2. API estável + prepaid real  
3. Specter/HIL como sensores oficiais de lab  
4. Saturn/DC = R&D de destino, não SKU principal
