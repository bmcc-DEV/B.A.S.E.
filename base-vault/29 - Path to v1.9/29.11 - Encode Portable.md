# Encode portátil (WASM-friendly)

Em vez de binutils cross no host:

```text
SIR ops → encode_* (Rust puro) → .bin
```

- Sem `mips-linux-gnu-as` / `sh-elf-as`
- Compilável a **wasm32** com o resto do crate (sem Capstone/C++)
- Keystone C++ **não** é dependência default

```bash
base recomp encode --hex B80100000083C002C3 --target sh2 -o output/enc
base recomp encode --hex 90C3 --target mips -o output/enc_mips
```
